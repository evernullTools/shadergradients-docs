# Welcome to ShaderGradients Documentation

ShaderGradients is a simple tool that gives you an easy way to put Gradients as exposed properties for your materials. 
It bakes the gradients into very small textures on the background, keeping the runtime performance cost negligible.

## Dependencies

The ShaderGradients package has no dependencies. Works with both Shader Graph and HLSL/ShaderLab shaders. 
It was tested in Unity version 2022.3 and Unity version 6000.5.
